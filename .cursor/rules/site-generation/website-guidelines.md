# Site Generation

A personal site that looks like a designer made it for themselves.

## Structure

1. Name
2. Role or one-liner
3. Short bio (2-3 sentences max, links inline)
4. Projects as simple list (title → description → link)
5. Subtle footer with short philosophy based on my data tied to location/weather

## Typography & Layout

- One elegant serif or sans-serif (not Inter, Roboto, system fonts)
- Max-width ~600px, generous margins
- Size and weight create hierarchy — nothing else needed
- Links: underlined or plain with subtle hover

## The feel

The best personal sites are confident enough to be sparse. They show name, role, current context, links to work — then stop. No decoration. No filler. Typography and whitespace do the heavy lifting.

What earns its place: identity, what you're working on, where to find your work.

What doesn't: gradients, cards, shadows, uppercase labels, hero images, decorative flourishes.

## Never

- Card shadows or borders
- Pill buttons or tags  
- Purple/blue gradients
- Hero sections
- Monospace fonts
- Uppercase section labels
- Em-dashes

## Technical

- Single HTML file, inline CSS
- Mobile-first (375px baseline)
- External links: `target="_blank" rel="noopener"`
