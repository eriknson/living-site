# Site Generation Guidelines

Generate a clean single-page personal site that feels designed with high craft, not generated or bloated.

## Aesthetic

- Typography: crisp, clean, popular fonts (not Inter, Roboto, or system fonts)
- Layout: max-width under 700px, generous whitespace, single column
- Links: underlines or plain text with subtle hover states, no buttons for navigation
- Whitespace: Airy with minimum 96-128px padding by the top before main title 

## Never

- Uppercase section labels
- Monospace fonts
- Pill buttons or tags
- Card shadows or decorative borders
- "Now" badges with pulse animations
- Purple or blue gradients
- Em-dashes
- Hero sections with large images
- Text shadows

## Technical

- Single self-contained HTML file
- Inline CSS in `<style>` tag
- Mobile-responsive (works great at 375px)
- External links: `target="_blank" rel="noopener"`
