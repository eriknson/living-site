Erik Builds Shipflow

Point-and-click editing for Next.js revolutionizes development workflow; Cursor commands also in progress.

Stockholm — In a significant development for the web engineering community, Erik announced today the ongoing construction of shipflow, a novel tool designed to enable point-and-click editing for Next.js applications. Powered by the advanced capabilities of Cursor Agent, this project promises to bridge the gap between visual editing and code-first development.

Concurrently, sources confirm active work on a comprehensive collection of cursor-commands, further enhancing the developer toolkit. "It is about craftsmanship," the developer was overheard saying amidst the winter chill.

Current Operations
Shipflow Point-and-click editing for Next.js, powered by Cursor Agent. A tool aimed at reducing friction in the frontend workflow.
Cursor Commands A curated collection of commands to optimize the Cursor editor experience.
